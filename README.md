# Biblioteca de Processo VIP

Landing page da oferta exclusiva da Biblioteca de Processo do Professor Costa Machado.

## Visualização local

Abra `dist/index.html` em um navegador.

## Estrutura

- `dist/index.html`: página principal
- `dist/styles.css`: estilos
- `dist/script.js`: interações e contador
- `dist/assets/`: imagens da página
